# UI/交互打磨计划（基于 alpha 1.2，2026-07-04 玩家反馈 16 条）

> 总原则（反馈⑯）：**精简 HUD，把关键交互放到桌面上**——玩家的视线应该落在赌桌，而不是挤在
> 屏幕下方的一小块 2D 面板。凡是"桌上能表达的"，就用毡面浮字/桌面物件表达；凡是"低频信息"，
> 就收进设置面板或账本。逐阶段交付，每阶段做完先验收再进入下一阶段。

## 阶段一 · 手牌与拖拽手感（反馈①②③④⑬）

| # | 现状 | 目标 | 验收标准 |
|---|------|------|----------|
| ① | 手牌横排微弧、牌厚 0.05 互相穿模；悬停=整张上移+放大 | **扇面平行层**方案（第一版"滚转+错深"仍穿模，已打回重做）：所有牌严格平行于同一扇面、沿法线一张压一张（右牌在上）、绕腕部枢轴刚体张开——**平行层几何上不可能穿模**；手里的牌额外压薄（纯视觉）；悬停=沿这张牌自己的长轴**层内滑出一截**，遮挡关系不变（仍被右邻压着），才读作"抽牌"而非"抬起" | 满手牌（10+ 张）任意角度无穿模；悬停读作从手里抽出 |
| ② | 只能拖进圈 | 悬停任一手牌**短按点击**=直接飞入自己的下注圈（长按仍拆分、拖动仍拖拽）；**出牌一律反面朝上**（下注保密）：点击入圈顺势扣成反面，拖拽携带中即已是反面 | 点一下牌，弧线飞进圈内槽位反面落定；点圈内牌仍可收回 |
| ③ | 携带点=指针射线打到桌面再抬高 0.55，牌浮在指针上方；抓起瞬间姿态突跳 | 指针射线直接与**携带高度平面**求交——牌钉在鼠标正下方；落点判定改按"指针所指的毡面点"；抓起姿态从手中四元数**平滑过渡**到反面携带姿态（尺寸同步渐变，无任何跳变）；协商拖拽同修 | 拖拽全程牌不偏离鼠标、无姿态/尺寸跳变；对准圈松手即入圈 |
| ③+ | （新功能，用户提出"捋牌"，实现为方向手势） | 按下后**竖着拉=拽出这一张**；**横着扫=捋牌**——扫过的牌逐张聚成拇指下的一叠、实时显示 ¥ 合计；不松手**上提=整叠转为携带**拖到桌上一次下注；松手仍在手里=散回展扇 | 横扫聚叠流畅、计数正确；整叠可拖进圈；松手可取消 |
| ④ | look.y 过阈值→手牌整体二段式收起，生硬 | 类 Minecraft 持图手感：手牌组带**旋转滞后摆动**（甩视角牌跟着晃）；收放为连续量——抬头渐收进怀里，低头牌微微举近端详 | 甩鼠标有惯性摆；抬头/低头是平滑连续的收放 |
| ⑬ | 眼高 1.82 / 后退 0.62，自己的椅背入画 | 相机略高略远（1.98 / 0.82）；非自由视角**不渲染自己的椅子**（与不渲染自己身体一致） | 正常视角看不到自己的椅子；桌面与对家更完整 |

## 阶段二 · 桌面提示与按键（反馈⑤⑩⑪⑫）

### 阶段二 · 验收修订轮（2026-07-04 反馈，已落实）

| # | 修订 |
|---|------|
| 修① | 空格键帽改用 `[␣]` 形式（用户钦定）；标准 ␣ 太短 → 位图字体手绘 **11 列宽体 ␣ 字形**，PixelText 改为逐字变宽步进（`glyphWidth`），`|________|` 退役 |
| 修② | 浮字双锚点：LOBBY/DISCUSSION（圈内不会有钱）悬在**圈正上方**；BETTING 起（圈内可能有钱，哪怕当前没有）**自动阻尼滑到西北锚点**。统一载体 `scene/PromptFloat.jsx`，姿态存模块级、跨组件（FeltPrompts→HandLayer→PayoutLayer）换装不跳位 |
| 修③ | 下注完成等待他人时浮字不消失：保持 `已下注 ¥N`（FeltPrompts 新增 BETTING 分支，飞牌落定后浮现）；此时自己钱堆上的 ¥ 标签隐藏（Scene3D 侧让位，2D 输入模式不受影响） |
| 修④ | REVEAL 确认后只显示 `已确认 x/y`（删去"等待其他玩家"尾巴） |
| 修⑤ | 浮字受击动效（二版定稿）：只给**非交互**文字行（等待时的小玩具）；整块板子**顺着点击位置被推一把**——CSS perspective+rotate3d 伪 3D，戳哪边哪边倒进去、戳正中直沉，衰减晃回正（`PromptFloat#pushFloat`，WAAPI 按点击点现算）。可交互行/拿取 [F] **不加**（按钮要干脆确定的反馈） |

## 开放问题（验收时请拍板）

1. 大厅"准备/取消准备"只是**协调信号**（房主仍可随时开局），还是要**门槛**（全员准备才能开）？当前按前者实现。
2. REVEAL 确认、REFLIP（暴食者重掷）是否也迁到桌面浮字？当前计划：REVEAL 迁、REFLIP 暂留底部（它有两个互斥按钮）。
3. 顶栏最终形态：仅留右上「设置 + 退出」，左上完全交给任务风 HUD——阶段名是否还需要显示？当前计划：并入任务风 HUD 首行。
