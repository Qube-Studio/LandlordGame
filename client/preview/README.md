# 视觉验证画廊（preview/）

离线核对「表现层」视觉的工具，不连后端、不开整局游戏。改动 UI / 美术 / 动画后，开这个页面扫一眼即可。

## 跑法

```bash
npm run dev            # 仓库根目录
```

然后浏览器开 **http://localhost:5173/preview/gallery.html**

顶栏切换场景。`gallery.html` / `gallery.jsx` 不是 Vite 构建入口，`npm run build` 不会打包它们。

## 加新场景（以后也这么做）

编辑 `gallery.jsx` 的 `SCENES` 数组加一项：

- `kind:'game'`：给一份 mock `state`（服务端 `viewFor` 的镜像），会挂载真实 `<GameScreen/>`，
  所以 HUD / 面板 / 投保槽 / 硬币都是线上同一套组件——改了组件这里自动跟着变。
- `kind:'grid'`：纯 props 组件（角色形象 / 钱牌那种），在 `gallery.jsx` 里直接写渲染。

mock `state` 的字段对照 `server/Room.js` 的 `viewFor()`。预览里把 `send` 换成了 no-op，
所以「确认下注」之类只跑前端动画、不报网络错。
